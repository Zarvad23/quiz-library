- Проверки синтаксиса всех PHP-файлов и JavaScript пройдены.

- 40 параллельных команд: для каждой bootstrap, регистрация, получение игры, черновик, отправка и три опроса игры. Все ответы сохранены, каждая команда получила ожидаемый балл. В последнем прогоне медиана полного сценария — 1,67 с, максимум — 1,75 с.
- Chromium через superpowers-chrome: проверены страницы входа, коллекции, конструктора, оформления участника и монитора на 40 команд; создание и сохранение вопроса, добавление/изменение текста на холсте, перемещение через PointerEvent, открытие детализации ответа и сохранение ручной оценки в мониторе, создание команды, выбор и отправка ответа. На ширине 390 px выбранный ответ восстановился после перезагрузки, прохождение продолжилось, горизонтальной прокрутки не было. Коллекция осмотрена на 1440 px.

Ограничения проверки: реальный Windows/XAMPP и Wi-Fi организатора недоступны; Apache .htaccess, брандмауэр, пропускную способность сети и воспроизведение пользовательских видео на реальных телефонах нужно проверить при установке по README. Программный нагрузочный тест не заменяет репетицию мероприятия.

## Поиск PHP в Windows/XAMPP — 1.0.2 / 18.11.2026

Исправлен поиск CLI, который в 1.0.1 опирался на PHP_BINDIR и PHP_BINARY и мог не находить php.exe под Apache в XAMPP. Новый поиск предпочитает каталог загруженного php.ini, учитывает фактический extension_dir, соседний с Apache каталог PHP и предков каталога сайта, не использует PATH. PHP_BINARY=httpd.exe не принимается за CLI. В proc_open передаётся активный php.ini через -c, рабочий каталог — каталог PHP. Кэш проверки имеет отпечаток окружения, старые сообщения об отключённых расширениях после смены окружения/перезапуска не используются.

Пройдены tests/php-discovery.py/php: моделирование C:\xampp, другого диска, пробелов, неправильного compile-time bindir, отсутствующего INI, Apache sibling и site ancestor fallback, точной версии Linux CLI и отказа httpd.exe. Реальным дочерним PHP проверена передача отдельного INI с пробелами в пути; проверен сброс старого и legacy-кэша с сохранением актуальной ошибки. tests/run-all.py пройден целиком, включая безопасность, восстановление, откат, оформление и 40 команд. Это проверки путей Windows и реального PHP в Linux; Windows/XAMPP в контейнере не запускались.

Онлайн-проверка минимального исправления: из опубликованного пакета 1.0.1 создана отдельная установка, заменён только server/updater.php из 1.0.2, искусственно сохранено прежнее сообщение об отсутствующем curl. Проверено, что номер остаётся 1.0.1, старый кэш не показывается, настоящий выпуск 1.0.2 скачивается и устанавливается через прежний API 1.0.1. Проверены сохранение всех строк базы/пароля/ответа/media и откат с сохранением новых изменений. Команда: QUIZ_BOOTSTRAP_ARCHIVE=<archive-1.0.1> python3 tests/update-github.py. Полный выпуск и отдельный bootstrap-fix опубликованы в GitHub; cloud checks выпуска пройдены.
