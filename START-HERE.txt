ПЕРЕПЛЁТ — УСТАНОВКА НА НОУТБУК

Нужна рекомендуемая сборка: XAMPP for Windows 8.5.12, 64 bit, с PHP 8.5.12.
Официальная загрузка: https://www.apachefriends.org/download.html
Номер версии относится к сборке с PHP, не к XAMPP Control Panel.
На ноутбуке используйте современный Chrome или Edge.

1. Установите XAMPP, например в C:\xampp.
2. Полностью распакуйте архив. Папка должна оказаться здесь:
   C:\xampp\htdocs\quiz-library
   Проверьте, что index.php находится прямо в этой папке.
3. В XAMPP Control Panel откройте Apache -> Config -> PHP (php.ini).
   Включите строки, убрав ; в начале, если он есть:
   extension=pdo_sqlite
   extension=mbstring
   extension=fileinfo
   Для загрузки крупных видео при необходимости задайте:
   upload_max_filesize=64M
   post_max_size=70M
   Сохраните php.ini. Если Apache работал, перезапустите его.
4. В распакованной папке quiz-library запустите setup-windows.cmd.
   После проверки окружения введите СВОЙ пароль ведущего (от 12 символов).
   Пароля от разработки в архиве нет. Пароль при вводе в консоли виден.
5. В XAMPP Control Panel нажмите Start у Apache.
   MySQL/MariaDB и остальные службы запускать не требуется.
6. На ноутбуке откройте: http://localhost/quiz-library/
   Войдите ведущим и запустите нужную викторину.

ТЕЛЕФОНЫ И ДРУГИЕ УСТРОЙСТВА

Подключите ноутбук и устройства к одной сети.
Узнайте IPv4 ноутбука командой ipconfig в Windows.
При IP 10.86.4.58 участники открывают:
http://10.86.4.58/quiz-library/

Это адрес для стандартного Apache на порту 80.
Порт 8093 и проброс через VS Code для XAMPP НЕ нужны.
Если Apache настроен на 8080, адрес будет:
http://10.86.4.58:8080/quiz-library/

Разрешите Apache в брандмауэре Windows для своей локальной сети.
В гостевой Wi-Fi сети устройства могут быть изолированы друг от друга.
IP на другом ноутбуке или в другой сети может отличаться.

ЧТО ПЕРЕНЕСЕНО

Две викторины, оформление и загруженные изображения сохранены.
Команды, ответы, история игр, старые сеансы и пароль не перенесены.
После установки нужно задать новый пароль и запустить новую игру.

ПРОВЕРКА ПЕРЕД МЕРОПРИЯТИЕМ

- Адрес http://localhost/quiz-library/data/library.sqlite должен
  возвращать 403 (доступ запрещён), а не скачивать базу.
- Откройте сайт с телефона и отправьте пробный ответ.
- Убедитесь, что картинки видны и монитор ведущего обновляется.
- Отключите сон ноутбука на время мероприятия.

Если настройка пишет об ошибке PHP, используйте XAMPP Shell:
cd C:\xampp\htdocs\quiz-library
php server/check.php
php server/setup.php

Подробности, резервное копирование и решение проблем: README.md.
