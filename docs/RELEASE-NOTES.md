Первый выпуск с обновлениями из панели ведущего.

- Отдельный раздел «Обновления» с текущей версией и описанием нового релиза.
- Автоматическая проверка при работе ведущего, установка только по кнопке.
- Проверка SHA-256 пакета и каждого файла, совместимости и синтаксиса PHP.
- Блокировка установки во время игры и общая блокировка запросов при замене файлов.
- Резервная копия кода и базы перед установкой; восстановление при ошибке проверки.
- Откат к предыдущему коду с сохранением данных, введённых после обновления.
- recover-updates.cmd для восстановления после выключения питания или прерывания процесса.

Включены все прежние возможности: типы слайдов, несколько полей, ссылки, управление показом, монитор с закреплёнными баллами, оформление и сброс.

Проверена загрузка GitHub на PHP 8.5; сетевой код совместим с PHP 8.1–8.5 без устаревшего curl_close.
