Исправление обновлений на Windows/XAMPP — 1.0.2.

- Поиск php.exe рядом с реально загруженным php.ini и относительно каталогов Apache/XAMPP; PATH не требуется.
- Поддержка установки XAMPP на другом диске и путей с пробелами.
- Проверка PHP и запуск после обновления используют тот же php.ini, что и сайт.
- Старое сообщение про curl сбрасывается после изменения окружения PHP и перезапуска Apache.

Если в версии 1.0.1 установка заблокирована сообщением «Не найден php.exe», используйте небольшой архив quiz-library-xampp-fix.zip: замените только server/updater.php, перезапустите Apache, затем обновитесь до 1.0.2 через панель. Можно также установить полный пакет поверх по обычной инструкции.

Данные викторин, загруженные материалы, ответы и пароли не меняются.
