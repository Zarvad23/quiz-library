ПЕРЕПЛЁТ — ОБНОВЛЕНИЕ 1.0.0 / 18.11.2026 (ОБНОВЛЕНИЯ ЧЕРЕЗ GITHUB)

Этот архив предназначен для установки ПОВЕРХ существующей платформы.
В нём нет папок data и uploads, базы, паролей, викторин и ответов.
Он не заменяет архив первоначальной установки.

1. Завершите мероприятие. Закройте вкладки платформы и остановите Apache
   в XAMPP Control Panel.
2. Сделайте резервную копию всей установленной папки quiz-library,
   включая data и uploads.
3. Распакуйте quiz-library-update.zip. Скопируйте папку quiz-library
   в C:\xampp\htdocs с ОБЪЕДИНЕНИЕМ папок и заменой файлов.
   Не удаляйте существующую папку quiz-library перед копированием.
   Если XAMPP находится в другом месте, используйте его папку htdocs.
4. Запустите Apache.
5. Обновите страницы ведущего и участников через Ctrl+F5.

Не запускайте setup-windows.cmd повторно: существующий пароль сохраняется.
Не переносите data из архива первоначальной установки поверх рабочей базы.
Служебные таблицы управления показом и оценок полей создаются автоматически
при первом обращении к API. Существующие таблицы и данные не очищаются.

ЧТО ИЗМЕНИЛОСЬ

- Информационный слайд можно сохранить без текста, например с картинкой.
- Ошибка сохранения показывается заметным окном и постоянным списком
  проблем с номерами слайдов. Нажатие переводит к нужному полю.
- Конструктор сохраняет локальный черновик. После перезапуска браузера
  он доступен в разделе «Мои викторины» -> «Несохранённые черновики».
  Черновик хранится в том же браузере, на том же устройстве и адресе сайта.
  Не используйте приватный режим и не очищайте данные браузера до сохранения.
  После успешного сохранения соответствующий черновик удаляется.
- В конструкторе появился блок «Проведение викторины»:
  * «Результаты у участников» — можно отключить баллы и правильные ответы
    для этой викторины. «По общей настройке» сохраняет прежнее поведение.
  * «Ведущий открывает слайды по кнопке» — после запуска слайды закрыты.
    В «Мониторе игры» нажимайте «Показать слайд 1», затем следующий.
    Участник, прошедший уже открытые слайды, ждёт следующего открытия.
    Новые настройки проведения применяются при следующем запуске игры.
- Информационные слайды исключены из итоговых ответов и CSV.
  В мониторе они скрыты по умолчанию; флажок «Информационные слайды и ссылки»
  позволяет показать их при необходимости.
- Сохранение положения прокрутки в мониторе продолжает работать.

Требования не изменились: PHP 8.1+, pdo_sqlite, mbstring, fileinfo.
Для существующего XAMPP переустановка не требуется.

ДОПОЛНЕНИЕ: баллы перенесены в первый столбец перед командами.
Баллы и названия команд закреплены при горизонтальной прокрутке вопросов.

Монитор игры теперь переключается в той же вкладке, как другие разделы.

ДОПОЛНЕНИЕ 13.11.2026

- Новый тип «Несколько текстовых полей»: от 2 до 12 вопросов на слайде.
  У каждого поля своя подпись, допустимые ответы и баллы. Общий текст
  слайда необязателен. Сумма баллов рассчитывается автоматически.
- Верные поля приносят баллы независимо от остальных. Пустое поле
  приносит 0; полностью пустой ответ отправить нельзя.
- Каждое поле сохраняется в черновике участника. В мониторе видны
  все ответы, сходство и оценки. Баллы поля можно изменить отдельно.
  Частично верный ответ выделяется жёлтым.
- При разрешённом показе результатов участник видит разбор каждого поля.
  В CSV каждое поле — отдельная строка с оценкой и максимумом.
- Новый тип «Ссылка на материал»: активная кнопка открывает HTTP/HTTPS-ссылку
  в новой вкладке. Можно указать свой текст кнопки.
- В обычных вопросах ссылка добавляется через «Добавить ссылку на материал».
- Слайд-ссылка не приносит баллы, исключён из разбора и CSV.
  В мониторе его можно показать флажком «Информационные слайды и ссылки».
- Оба типа доступны в редакторе оформления и в JSON-экспорте/импорте.

Обновляйте именно с объединением папок: файлы data и uploads из рабочей
установки должны остаться на месте. Новый файл assets/question-types.js
также входит в обновление и должен быть скопирован.

ДОПОЛНЕНИЕ: ПОЛНЫЙ СПИСОК СТРАНИЦ И СБРОС ОФОРМЛЕНИЯ

- Добавлены отдельные страницы «Ожидание следующего слайда»,
  «Приглашение в новую викторину», «Завершение без результатов».
- Доступны общие шаблоны начала, вопросов и обоих вариантов завершения.
- У конкретной викторины также есть отдельное оформление завершения
  без результатов. Настройка показа ответов при этом не меняется.
- «Вернуть к дефолту» сбрасывает оформление выбранной страницы.
- «Сбросить всё оформление» после подтверждения сбрасывает оформление
  всех страниц сайта и всех викторин. Вопросы, медиа, ответы и баллы
  сохраняются. Сброс можно отменить кнопкой «Отменить».
- После сброса нажмите «Сохранить», чтобы применить его к сайту.

ОБНОВЛЕНИЯ ЧЕРЕЗ GITHUB — 1.0.0

Этот пакет один раз устанавливается поверх вручную по инструкции выше.
После установки в левой панели ведущего появится раздел «Обновления».
Источник: Zarvad23/quiz-library. Отдельный токен на ноутбуке не нужен.

Проверка новых версий выполняется автоматически при работе ведущего
с панелью (раз в час) или по кнопке. Установка — только по кнопке.
Во время активной игры обновление и откат запрещены.

Если показано требование PHP, откройте php.ini через XAMPP Control Panel:
уберите точку с запятой перед extension=curl и extension=zip, сохраните
и перезапустите Apache. Если proc_open отключён в disable_functions,
его также нужно разрешить. Без этого викторины работают, установка
обновлений — нет. Проверку сертификатов SSL отключать нельзя.

Программа сохраняет код и базу перед установкой. Папка uploads
при обновлении не изменяется. При ошибке проверки прежняя версия
и база восстанавливаются. Кнопка «Вернуть предыдущую версию» откатывает
код, сохраняя текущие викторины, оформление и ответы.

После неожиданного выключения ноутбука или прерывания PHP сайт может
попросить восстановление. Запустите recover-updates.cmd в папке сайта,
затем перезапустите Apache и нажмите Ctrl+F5.
Резервные копии: data/updater/backups. Они не удаляются автоматически.
Не публикуйте папки data и uploads в GitHub.
